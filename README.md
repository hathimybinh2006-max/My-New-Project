# My New Project

Dự án thực hành làm quen và làm việc với Git & GitHub.

## Giới thiệu
Repository này được tạo nhằm mục đích luyện tập các thao tác cơ bản:
- Khởi tạo Git repository cục bộ (git init)
- Liên kết với kho lưu trữ từ xa trên GitHub (git remote add origin)
- Theo dõi và lưu trữ thay đổi (git add, git commit)
- Đẩy dữ liệu lên GitHub (git push)
